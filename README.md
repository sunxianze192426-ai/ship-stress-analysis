## 使用方法

### 方式一: 在App Designer中续写 (推荐)

1. 打开 MATLAB → App Designer → 打开 `BoatMain.mlapp`
2. 切换到 **Code View**
3. 打开 `补充代码/BoatMain_Tab6_Tab10_补充代码.m`
4. 按文件中标注的**5个步骤**依次复制粘贴:

| 步骤 | 粘贴位置 | 内容 |
|------|----------|------|
| 第1步 | `properties (Access = public)` 末尾 (Label_56 之后) | Tab_6~10 UI组件声明 |
| 第2步 | `createComponents` 末尾 (`Visible='on'` 之前) | Tab_6~10 UI创建代码 |
| 第3步 | `methods (Access = private)` 末尾 | 回调函数 |
| 第4步 | `methods (Access = private)` 末尾 (callback之后) | 公用工具函数 |
| 第5步 | 构造函数中 `createComponents(app)` 之前 | 状态变量初始化 |

5. 保存并运行: `>> BoatMain`

### 方式二: 直接运行完整版

```matlab
% 将 BoatMain_完整版.m 放在MATLAB路径中
% 确保 boatt.png 和 denglu.jpg 在同一目录
>> BoatMain
```

## 新增Tab使用流程 (Tab_6~10)

1. 点击对应Tab标签 (如"蒸汽压力")
2. 点击"**选择数据**" → 选择对应CSV测试文件
3. 点击"**加载并分析**" → 系统自动:
   - 读取三列数据(标签/数值/单位)
   - 按标签分组 (同标签=同组)
   - 计算6项统计 (max/min/mean/rms/var/std)
   - 自动设置Y轴范围
4. 在设备列表中**单选或多选**设备
5. 查看**折线图**(时序对比)和**箱线图**(分布)
6. 右侧表格显示6项统计结果
7. 可手动调整**Y轴范围**，图表即时刷新
8. 点击"**导出图表**"保存为PNG/FiG

## 测试数据说明

每个CSV文件格式: `设备标签, 数值, 单位`

```
球阀1, 2.5, MPa
球阀1, 2.7, MPa    ← 同一设备, 不同时间点
球阀1, 2.3, MPa    ← 共10条记录
...
球阀2, 3.1, MPa    ← 另一设备, 10条
...
阀门1, 4.2, MPa    ← 另一设备, 10条
```

- 每个文件9种设备, 每种10条时序记录
- 同一标签自动归组, 多个时间点汇总统计
- 折线图自动适配: ≤50条→粗线+标记, ≤200条→中线+小点, >200条→细线
